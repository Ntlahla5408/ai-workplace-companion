# AI Workplace Companion

AI Workplace Companion is a web application prototype exploring an AI-assisted workspace for everyday work activities. The repository brings several work areas together under one application interface.

## Workspace areas

The current route structure includes dedicated areas for:

- **Dashboard** — a central workspace landing area
- **Chat** — conversational AI workspace
- **Tasks** — task-management area
- **Meetings** — meeting workspace
- **Email** — email-related workspace
- **Research** — research workspace
- **Settings** — application preferences

These describe the areas represented in the project structure; they should not be taken as a claim that every workflow is production-ready or connected to a live external service.

## Technology stack

- React 19
- TypeScript
- TanStack Start and TanStack Router
- Vite
- Tailwind CSS
- Supabase client integration
- Vercel AI SDK packages
- Radix UI-based component primitives

## Getting started

### Prerequisites

- Node.js and npm
- The backend/provider configuration required by the integrations used in the project

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

The available scripts are defined in `package.json`. The project also includes build, preview, lint and formatting scripts.

## Project status

This repository represents an evolving application prototype. Review the current implementation and configure the required external services before treating any workspace area as a complete, production-ready feature.
